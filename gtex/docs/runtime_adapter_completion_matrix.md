## Enforced In This Pass

- Frontend startup now fails outside Flutter tests when `GTE_BACKEND_MODE=fixture` or `GTE_BACKEND_MODE=liveThenFixture`.
- Backend production/staging startup now rejects demo fixture flags, mock ingestion, mock KoraPay, non-production startup profiles, and test auth fixture mode.
- `GteExchangeApiClient.standard` no longer registers `GteMockApi`.
- `NationalTeamApi.standard` no longer registers seeded fixtures.
- `ClubApi.standard`, `ClubIdentityApiRepository`, and `ClubSaleMarketApiRepository` no longer default to fixture/mock stores in strict-live runtime.
- `CompetitionApi.standard` and `HostedCompetitionApi.standard` no longer register seeded fixture stores in strict-live runtime.
- Admin engine, admin finance, community, regen universe, trader, story feed, notifications, launch control, club lifecycle, club growth, global search, matchday economy, sponsorship admin, risk ops, policy admin, moderation, governance, dispute, discovery, creator, and creator application standard clients no longer register seeded fixture stores in strict-live runtime.
- Frontend `.fixture()` constructors in `frontend/lib` are guarded by `assertFixtureFactoryAllowed(...)`; Reality Audit fails any new unguarded factory or `const` fixture constructor.
- Football world pulse widgets render explicit empty/error states instead of synthetic ticker activity or generated transfer routes.
- Production match execution workers disable synthetic squad fallback; tests must opt in explicitly.
- `GTE_ENABLE_LEGACY_MATCH_SIMULATION` is forbidden by protected backend startup and the simulation worker ignores it in production-like runtimes.
- Regen creation KoraPay initialization fails closed when live provider readiness is missing, uses the same whole-number KoraPay amount convention as wallet funding, and checks verified reference/currency/amount.
- Generated Infinite League live bridge and World Super Cup demo projections require explicit local/demo enablement and remain blocked by default in protected runtime modes; the generated live bridge is now hard-blocked in protected runtimes even if its env flag is present.
- Production/staging backend startup fails if `GTE_ENABLE_INFINITE_LEAGUE_LIVE_BRIDGE`, `GTE_ENABLE_WORLD_SUPER_CUP_DEMO`, or `GTE_ENABLE_PAYSTACK` are enabled.
- Paystack availability is hard-blocked in backend provider/admin surfaces and removed from selectable top-up/admin payment rail constants while KoraPay/manual remain the supported production payment paths.
- World Super Cup persisted authority includes tournament, countdown, coefficient, qualified-club, group, fixture, standing, and settlement idempotency tables plus persistence-service reads.
- Runtime observability metadata tags live endpoints, WebSocket sources, stale-payload threshold, and the backend source-of-truth tag.
- Match V2 production files no longer import `gtex_match_demo_repository.dart`; Reality Audit enforces this.
- Live match viewer timeline builders default synthetic visual identity off; protected routes require persisted viewer/replay visual identity or fail closed.
- Profile V2 uses `ProfileRuntimeAdapter` for canonical live profile/security/session/wallet/club endpoints; Reality Audit enforces those endpoint reads and no-club 404 handling.
- `validateGtexRuntimeAdapterGraph` now fails protected boot if the runtime registers fixture endpoints, unavailable/synthetic match repositories, fixture club repositories, fixture exchange repositories, fixture national-team repositories, fixture capabilities, missing realtime, or Paystack.
- Optional runtime health overlay is available behind `GTE_RUNTIME_HEALTH_OVERLAY=true`.
- Production observability includes strict-live blocked-state, payload-rejection, auth-rejection, realtime-reconnect, settlement-failure, queue-backlog, and correlation-ID signals.
- `tools/load/strict_live_runtime_load.py` is the strict-live HTTP load probe for live profile/admin/national/competition surfaces.
- `tools/audit/reality_audit.py` is the local/CI command for strict-live production checks.
- `tools/audit/reality_audit.py` now enforces explicit fixture opt-in for engagement notifications, chat, and news article demo helpers.
- `tools/audit/reality_audit.py` now enforces fail-closed defaults for shared club, match, and exchange hub providers.
- `tools/audit/reality_audit.py` now enforces strict-live observability/load harnesses, Paystack top-up removal, Phase 2 smoke markers, and World Super Cup persisted authority files.
- `tools/audit/reality_audit.py` scans the current code/config tree, generated/cache snapshots, and the latest reachable git history by default; set `GTE_REALITY_AUDIT_HISTORY_DEPTH=0` for a full local history scan before release.
